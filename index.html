How to use

Use Chrome or Edge on desktop. First copy the auditor code above, then open Instagram and use the shortcut for your computer:

Windows
Ctrl+Shift+I or F12
Opens Developer Tools in Chrome or Edge.
macOS / Mac
⌘ Command+⌥ Option+I
Opens Developer Tools in Chrome or Edge on a Mac.
  1. Click Copy code above.
  2. Open instagram.com on desktop and sign in.
  3. Press the Windows or Mac Developer Tools shortcut shown above.
  4. In DevTools, open Sources → Snippets. If Sources is hidden, use the >> overflow menu.
  5. Click + New snippet.
  6. Paste the copied JavaScript into the snippet.
  7. Click the ▶ Run button.
  8. The auditor will open over Instagram. Review the settings, then start the read-only scan.
Mac users: these instructions refer to Chrome or Edge on macOS. Safari's Web Inspector works differently and does not use the same Chrome/Edge Snippets workflow.
Read-onlyNo follow, unfollow, like, comment, or DM actions.
Local sessionRuns inside the Instagram session already open in your browser.
ExportableAudit results can be exported as CSV or JSON.
Important: Instagram's private web endpoints are undocumented and may change. Review identity-coverage confidence before treating a zero-interaction result as definitive inactivity.
