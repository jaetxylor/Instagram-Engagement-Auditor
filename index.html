Instagram Engagement Auditor V3

Analyze followers, following, post likes/comments, engagement confidence, profile engagement rate, non-followbacks, and optional following-to-follower ratios — inside your existing Instagram browser session.

View source GitHub repository
Loads the current script from this repository when you click Copy.

How to use

  1. Click Copy auditor code.
  2. Open instagram.com on desktop and sign in.
  3. Open Developer Tools and go to Sources → Snippets.
  4. Create a new snippet and paste the copied JavaScript.
  5. Run the snippet.
  6. Review the scan settings, then start the read-only audit.
Important: Instagram's private web endpoints are undocumented and may change. Review identity-coverage confidence before treating a zero-interaction result as definitive inactivity. The tool does not automate unfollows or other account mutations.
