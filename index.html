How to use

  1. Click Copy code above.
  2. Open instagram.com on desktop and sign in.
  3. Open Developer Tools.
  4. Go to Sources → Snippets.
  5. Create a new snippet and paste the copied JavaScript.
  6. Run the snippet.
  7. Review the scan settings, then start the read-only audit.
Read-onlyNo follow, unfollow, like, comment, or DM actions.
Local sessionRuns inside the Instagram session already open in your browser.
ExportableAudit results can be exported as CSV or JSON.
Important: Instagram's private web endpoints are undocumented and may change. Review identity-coverage confidence before treating a zero-interaction result as definitive inactivity.
